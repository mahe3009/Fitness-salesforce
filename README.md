# 🏋️ FitHub CRM - Fitness Center Management

## 📌 Project Overview

**FitHub CRM** is a fitness center management system designed to simplify and digitize gym operations. It helps manage members, track attendance, monitor subscriptions, and analyze performance through a centralized dashboard.
